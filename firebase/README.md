# Firebase Setup Notes

1. Create/select the actual Firebase project.
2. Register the exact Android application ID generated by AI Studio.
3. Enable Google in Firebase Authentication.
4. Configure SHA fingerprints as required for Google Sign-In.
5. Enable Cloud Firestore in the selected region.
6. Configure Firebase in AI Studio using its supported setup flow.
7. Obtain the correct `google-services.json` for the registered Android app and place it only in the local Android app module.
8. Never commit that file, service-account keys, private keys or signing credentials to this public repository.
9. Review and replace the conservative starter rules in `firestore.rules` with tested rules matching the final schema.
10. Test with at least two separate accounts.

The rules file deliberately denies writes to user subcollections until trusted session, wallet, XP, challenge and purchase flows are defined. Do not deploy it as a claim of complete application functionality; use it as a secure starting guardrail.
