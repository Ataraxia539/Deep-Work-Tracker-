# Starter Code

This folder contains small deterministic domain helpers for AI Studio to integrate into the generated Android project. They are not a complete Android app and are not a substitute for the master blueprint.

- `CoinEarningMath.kt`: exact rational coin calculation helper.
- `CoinEarningMathTest.kt`: unit tests for the exact calculation.

The agent should move these into the generated app's appropriate source/test packages, adapt package declarations if needed, and run the tests. Do not change the math to rounded floating-point per-second rewards.
